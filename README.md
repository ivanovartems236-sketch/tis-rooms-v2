# Кабинеты ТИС v2 — «Куда идти?»

Расписание ТИС (филиал ДГТУ) по аудиториям, группам и преподавателям — на основе файлов с https://stis.su/schedule.

**Что умеет** — «Куда идти?»
- Первый запуск: «Я студент / Я преподаватель / Просто посмотреть» → выбор группы или себя. Без регистрации: профиль хранится только в браузере
- **Сегодня:** карточка «куда идти» — аудитория крупно, через сколько пара, сколько осталось; список дня с окнами, метками «изменено» / «отменено»
- **Неделя:** вся неделя пн–сб одним экраном
- **Найти:** единый поиск по группам, аудиториям, преподавателям; для преподавателей — свободные аудитории по корпусам и «свободна N пар подряд»
- **Ещё:** замены для своего профиля, подписка-календарь (.ics), Шахматка (для преподавателей), профили
- Профили-переключатель наверху, кнопка «назад», «Поделиться» картинкой дня/недели (рисуется в браузере, со ссылкой на живое расписание)
- Ссылки на конкретный вид (`#group/О-Исп-9-251`, `#room/К-121`, `#teacher/…`, `#free`, `#grid`), офлайн-режим, установка на экран «Домой»
- Лента изменений + уведомления в Telegram
- Виджет для iPhone через Scriptable (`widget-scriptable.js`), в т.ч. на экран блокировки
- Демо-время для проверки: `?now=2026-10-27T10:40`

Загрузка аудиторий (аналитика) убрана из интерфейса — код в истории git (`app.js` до v3), вернуть при необходимости.

**Устройство**
- `scraper/rasp.py` — скачивание и разбор xls
- `scraper/build.py` — пишет `data.json`, `changes.json`, `ics/`, шлёт изменения в Telegram
- `.github/workflows/update.yml` — тесты, затем сборка: 07:05 и 19:05 МСК пн–сб + вс 18:05
- `tests/` — тесты парсера на реальных файлах stis.su (`tests/fixtures/`)

**Защита данных.** Сборка останавливается и не трогает сайт, если не скачался хоть один файл,
не разобрано ни одного занятия или будущих занятий стало меньше на 40%+ (обойти: `--force`).
Выкладка нового расписания пишется в ленту одной строкой, а не сотней «добавлено».
- `index.html`, `app.js`, `style.css`, `sw.js` — сайт (GitHub Pages), ванильный JS без сборки

**Настройка**
1. Settings → Pages → Deploy from a branch → `main` / `(root)`.
2. Actions → «Обновление расписания» → Run workflow.
3. Telegram (необязательно): создай бота у @BotFather, добавь его в канал/чат, затем
   Settings → Secrets and variables → Actions → New repository secret:
   `TG_TOKEN` — токен бота, `TG_CHAT` — id чата или `@имя_канала`,
   `TG_ADMIN` — твой личный chat id для алертов о сбоях сборки (необязательно).

**Локально**
```
pip install openpyxl pytest
python -m pytest -q                   # тесты
python scraper/build.py               # скачать и собрать
python scraper/build.py --from DIR    # собрать из скачанных файлов
python -m http.server                 # открыть http://localhost:8000
```
